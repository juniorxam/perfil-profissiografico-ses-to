# Perfil Profissiográfico — SES-TO

Protótipo demonstrativo do formulário baseado no documento **Propostas de Aplicação e Análise do Perfil Profissiográfico — SES-TO, Edital nº 001/2026**.

## Visualizar

Abra [index.html](./index.html) para consultar o código-fonte. Para publicar como site, habilite o GitHub Pages:

1. Acesse **Settings** deste repositório.
2. Abra **Pages** no menu lateral.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch **main** e a pasta **/(root)** e salve.
5. Aguarde o endereço publicado aparecer na própria tela do GitHub Pages.

## Escopo desta demonstração

- O formulário está dividido nos Blocos 0 a 7, com os 28 itens descritos na proposta.
- Os Blocos 1 a 6 são apresentados como obrigatórios; o Bloco 7 — Equidade e Acessibilidade — é voluntário.
- A tela funciona localmente no navegador e não envia nem persiste respostas.
- Cargo/especialidade e município de lotação aparecem como campos previstos para preenchimento automático pelo cadastro, conforme a proposta.

## Atenção antes de uso real

Este protótipo **não está pronto para coletar dados reais**. A proposta trata as informações como sensíveis e prevê preenchimento voluntário, sigiloso e uso exclusivo para apoio ao acolhimento — nunca para avaliação de desempenho, aprovação/reprovação ou decisões de permanência.

Antes da aplicação oficial, devem ser definidos e implementados armazenamento protegido, autenticação, controle de acesso, responsabilidades pelo tratamento, retenção e procedimentos de atendimento à LGPD. O instrumento não deve produzir alocação automática: a proposta recomenda utilizar os resultados como ponto de partida para conversa com o próprio servidor.
